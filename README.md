You can Either use `MinGW 64` or `MSVC` toolchains to Develop and run the following applications

Ex for MINGW64
```bash

cd /TO-CURRENT_FOLDER/
g++ [FILENAME] -o [EXECUTABLE DIRECTORY]

```

Ex for MSVC
```bash

cd /TO-CURRENT_FOLDER/
cl.exe [FILENAME]
```
